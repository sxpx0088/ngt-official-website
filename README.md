# NGT — NextGen Ecosystem website

Static, responsive informational website prepared for GitHub Pages.

## Publish with GitHub Pages
1. Create or open the public GitHub repository intended for the NGT website.
2. Upload the contents of this folder to the repository root (the `index.html` file must be at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The URL normally looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before submitting the URL to BscScan
- Confirm the displayed contract address is correct.
- Add only verified official email, documentation, social profiles, tokenomics, sale or burn information.
- The site deliberately avoids unverified claims and does not provide financial advice.
- GitHub Pages publication does not guarantee that BscScan will approve the website link.
